# Claro neutro

**Cuándo:** documentación, informes, contenido técnico. Cuando la prioridad es
que se entienda a la primera y el tono no debe llamar la atención.

## Parámetros
```yaml
tratamiento: impersonal      # "se corta el alambre"
persona: tercera
densidad: media
tecnicismos: se usan sin explicar, se asume lector informado
ritmo: frases de largo medio, una idea por frase
```

## Antes → después
- "Vas a necesitar un alambre" → "Se requiere alambre calibre 22"
- "Ojo con esto" → "Importante:"
- "Es súper importante que" → "Es necesario que"

## Nunca
- Voz pasiva encadenada ("habiendo sido efectuado el corte")
- Adjetivos valorativos ("excelente resultado", "hermoso acabado")
- Preguntas retóricas
