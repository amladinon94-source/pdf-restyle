# Editorial

**Cuándo:** contenido que se lee por gusto, no por necesidad. Catálogos,
piezas de marca, contenido estacional con intención narrativa.

## Parámetros
```yaml
tratamiento: impersonal con momentos en segunda persona
persona: mixta
densidad: media-alta         # se permite un párrafo largo si tiene ritmo
tecnicismos: se usan como parte del oficio, con orgullo
ritmo: variado — alterna frases largas y cortas
```

## Antes → después
- "Materiales requeridos" → "El material"
- "Corta 12 tallos de eucalipto" → "Doce tallos de eucalipto, cortados a 25 cm"
- "Este paso es importante" → "Aquí se decide el resultado"

## Nunca
- Publicidad encubierta ("el mejor", "incomparable")
- Metáforas que no aporten información
- Perder el dato concreto por hacer una frase bonita
